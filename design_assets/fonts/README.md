# Fontes dos layouts

Arquivos originais do repositório Google Fonts, distribuídos sob SIL Open Font
License. As licenças completas acompanham cada família. Os arquivos das fontes
não foram modificados; a renderização seleciona o peso da fonte variável.

- Cormorant Garamond: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope

Não colocar originais do Drive ou artes da empresa nesta pasta pública de código.
