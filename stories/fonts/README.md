# Fontes da prévia de Stories

Distribuições originais sem alteração, com licença SIL Open Font License 1.1:

| Arquivo | Origem | Licença incluída |
| --- | --- | --- |
| `playfairdisplay.ttf` | [Google Fonts — Playfair Display](https://github.com/google/fonts/tree/main/ofl/playfairdisplay) | `playfairdisplay-OFL.txt` |
| `greatvibes.ttf` | [Google Fonts — Great Vibes](https://github.com/google/fonts/tree/main/ofl/greatvibes) | `greatvibes-OFL.txt` |
| `manrope.ttf` | Cópia de `design_assets/fonts/manrope.ttf` do projeto | `manrope-OFL.txt` |

Os hashes exatos estão em `stories/assets/layout.json`. A seleção de peso é feita
pela API da fonte variável em memória; os arquivos não são modificados.
Essas fontes reproduzem o estilo da imagem de referência; não há confirmação de
que sejam as mesmas usadas para criar a imagem original.
